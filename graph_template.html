Port cones on

def2graph traces each top-level pin through plain logic until it reaches a flop or a memory. This page draws those cones on the placement. Select a pin to see its cone and endpoints. Select a memory bank to see which pins reach it.

    Which buses reach which banks

    Each cell counts the cone endpoints on that bank from the bus's pins. Hover over a cell to see the count when cells are too narrow to show it. A bus with an empty row reaches flops only. Click a cell to select the bank.

    Wire length against logic depth

    One dot per cone endpoint. Wire length is the sum of pin-to-pin Manhattan distances along the longest path from the top-level pin to the endpoint pin, through the cone's gates. With no routing, it is a lower bound. Depth is def2graph's count of cells on the path, the endpoint included. Click a dot to select its pin.
