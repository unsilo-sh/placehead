Port cones on

def2graph traces each top-level pin through plain logic until it reaches a flop or a memory. This page draws those cones on the placement. Select a pin to see its cone and endpoints. Select a memory bank to see which pins reach it.

    Which buses reach which banks

    Each cell counts the cone endpoints on that bank from the bus's pins. A bus with an empty row reaches flops only. Click a cell to select the bank.

    Distance against logic depth

    One dot per cone endpoint. Distance is Manhattan, from the pin to the centre of the endpoint cell, in µm. Depth is def2graph's count of cells on the path, the endpoint included. Click a dot to select its pin.
